# Pokémon-PHP

A simple web application built with **PHP** and **MySQL** that displays and filters a list of Pokémon based on various attributes such as type, attack, defense, speed, and HP (hit points).

## Technologies Used

- **PHP** – Server-side logic
- **MySQL** – Relational database to store Pokémon data
- **HTML/CSS + JavaScript** – Frontend interface
- **Bootstrap** – Responsive UI design
- **jQuery (for AJAX)** – Handles asynchronous requests for filtering without reloading the page

## Features

- Display Pokémon with detailed attributes:
  - Name
  - Types
  - HP, Attack, Defense, Speed
- Dynamic filtering:
  - By type (e.g., Grass, Fire, Water)
  - By name (search bar)
  - By stats using sliders (attack, defense, speed)
- Responsive, card-style layout for each Pokémon

## Requirements

- PHP 7.4 or higher
- Web server (e.g., Apache, Nginx)
- MySQL or MariaDB
- A modern web browser
